# Coordination index: where each lane's coordination lives

Read this before starting cross-assistant work. If a thread or session isn't listed here,
it isn't a coordination channel. Update this file when a thread is opened, retired or
moved, and add a line to the change log at the bottom.

## Naming convention
Thread titles: `[LANE] role · detail`, e.g. `[RK] lane · Claude Code · active`.
Keep standing threads few: one per active lane; reviews and one-off work run in temporary
contexts and file their results here.
